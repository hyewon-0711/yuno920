# 활동 분석 기능 설계

## 목표

윤호가 현재 하고 있는 활동을 간단히 등록하고, AI가 활동의 균형과 적절성을 분석해 부모에게 유지·조정·추가 추천을 제공한다.

MVP에서는 입력 부담을 낮추기 위해 활동 추가 시 아래 3가지만 받는다.

- 활동명
- 영역
- 빈도

## 메뉴 구조

신규 상위 메뉴: `활동`

하단/사이드 내비게이션 권장 순서:

- 홈
- 활동
- 성장
- 기록
- 인사이트

`활동` 메뉴는 기존 `주간 시간표`와 다르다.

- 주간 시간표: 언제 무엇을 하는지 관리
- 활동 분석: 현재 하고 있는 활동 구성이 적절한지 판단

## 핵심 화면

### 1. 활동 메인

상단:

- AI 활동 적절성 점수
- 요약 문장
- 주요 상태 칩

예:

- `현재 구성은 좋은 편이에요`
- `부담도 보통`
- `신체 충분`
- `창의 보완`

중단:

- 진행 중인 활동 목록
- 각 활동 카드에는 활동명, 영역, 빈도, AI 판단 표시

하단:

- 최근 AI 분석 요약
- `AI 분석 다시 하기` 버튼

### 2. 활동 추가

`+` 또는 `활동 추가` 버튼을 누르면 모달 또는 바텀시트가 열린다.

입력 항목:

| 항목 | 타입 | 예시 | 필수 |
| --- | --- | --- | --- |
| 활동명 | 텍스트 | 태권도, 피아노, 수학 학원 | 필수 |
| 영역 | 선택 | 학습, 신체, 예술, 사회성, 정서, 독서, 생활습관, 기타 | 필수 |
| 빈도 | 선택 | 매일, 주 1회, 주 2회, 주 3회, 주 4회 이상, 비정기 | 필수 |

저장 후:

- 활동 목록에 바로 추가
- AI 분석은 자동 실행하지 않는다
- 사용자가 `AI 분석하기`를 누르면 최신 활동 목록 기준으로 분석

### 3. 활동 수정

활동 카드를 누르면 수정 모달이 열린다.

수정 가능 항목:

- 활동명
- 영역
- 빈도

하단 액션:

- 저장
- 삭제

삭제는 native `confirm()` 대신 앱의 `Modal` 컴포넌트를 사용한다.

### 4. AI 분석 결과

분석 버튼을 누르면 다음을 보여준다.

| 항목 | 설명 |
| --- | --- |
| 전체 적절성 점수 | 0~100 |
| 요약 | 부모가 바로 이해할 수 있는 2~4문장 |
| 영역별 균형 | 학습, 신체, 예술/창의, 사회성, 정서, 생활습관 |
| 부담도 | 낮음, 보통, 높음 |
| 유지 추천 | 현재 유지해도 좋은 활동 |
| 조정 추천 | 빈도나 조합을 조정하면 좋은 활동 |
| 추가 추천 | 부족한 영역을 보완할 활동 |
| 부모 액션 | 이번 주 실천할 수 있는 1~3개 행동 |

분석 톤:

- 진단처럼 말하지 않는다.
- 부모를 비난하지 않는다.
- 활동을 단정적으로 금지하지 않는다.
- `참고용 AI 코칭`임을 명확히 표시한다.

## 데이터 설계 초안

### `child_activities`

윤호가 현재 하고 있는 활동 목록.

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| id | uuid | PK |
| child_id | uuid | children.id |
| title | text | 활동명 |
| area | text | 영역 |
| frequency | text | 빈도 |
| status | text | active, paused, ended |
| created_at | timestamptz | 생성일 |
| updated_at | timestamptz | 수정일 |

MVP에서는 `title`, `area`, `frequency`만 UI에서 입력한다.

추후 확장 후보:

- duration_minutes
- parent_goal
- child_reaction
- notes
- started_at
- ended_at

### `activity_assessments`

AI 분석 결과 저장.

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| id | uuid | PK |
| child_id | uuid | children.id |
| input_snapshot | jsonb | 분석 당시 활동 목록 |
| result_json | jsonb | AI 분석 원본 |
| summary | text | 요약 |
| score | integer | 전체 점수 |
| created_at | timestamptz | 생성일 |

## AI 입력

AI에는 활동 목록과 기존 데이터를 함께 전달한다.

활동 목록:

```json
[
  { "title": "태권도", "area": "신체", "frequency": "주 2회" },
  { "title": "수학 학원", "area": "학습", "frequency": "주 2회" },
  { "title": "독서", "area": "독서", "frequency": "매일" }
]
```

추가 컨텍스트:

- 아이 나이
- 최근 기록
- 독서 기록
- 성장/학습 기록
- 주간 시간표가 있으면 참고

## UX 상태

### 빈 상태

활동이 없을 때:

- 문구: `윤호가 하고 있는 활동을 추가해보세요`
- 버튼: `활동 추가`

### 분석 전 상태

활동은 있지만 분석 기록이 없을 때:

- 문구: `활동을 추가했어요. AI 분석으로 균형을 확인해볼까요?`
- 버튼: `AI 분석하기`

### 분석 중 상태

- 버튼 disabled
- 문구: `활동 구성을 분석하고 있어요`

### 분석 실패

- 문구: `분석을 가져오지 못했어요. 잠시 후 다시 시도해주세요.`
- 재시도 버튼 제공

### 데이터 부족

활동이 1개뿐이어도 분석은 가능하게 한다.

- 단, 결과에 `활동이 더 쌓이면 분석 정확도가 높아집니다` 안내 표시

## 구현 우선순위

1. Supabase migration: `child_activities`, `activity_assessments`
2. 활동 CRUD hook
3. `/activities` 페이지와 내비게이션 추가
4. 활동 추가/수정 모달
5. FastAPI AI 분석 endpoint
6. 분석 결과 저장 및 표시
7. Home 또는 Insight에 요약 카드 연결

## MVP 제외

초기 버전에서는 제외한다.

- 활동별 비용 관리
- 장소 관리
- 시작일/종료일
- 1회 소요시간
- 아이 반응 상세 기록
- 주간 시간표 자동 동기화

위 항목은 활동 관리가 실제로 사용된 뒤 확장한다.
