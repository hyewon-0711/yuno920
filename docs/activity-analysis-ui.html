AI 코칭 요약

수학 학원 뒤에는 회복 시간이 필요합니다. 주말에 창의 활동을 짧게 추가하면 전체 균형이 좋아집니다.

다음 액션

  • 수학 학원 후 자유 놀이 30분 확보
  • 주 1회 만들기 또는 음악 활동 추가
  • 2주 뒤 피로도와 반응 재평가
1. 활동 등록

활동명, 영역, 빈도만 입력합니다. 세부 키워드는 AI 분석에서 추론합니다.

2. 데이터 연결

주간 시간표, 일정, 기록, 독서, 성장 점수를 함께 참조합니다.

3. AI 분석

균형, 부담도, 나이 적합성, 유지·조정·추가 추천을 생성합니다.

4. 후속 관리

분석 결과를 저장하고 2주 뒤 다시 평가할 수 있게 합니다.

입력 모달과 분석 결과 화면

MVP에서는 모달 입력 후 결과 패널로 이어지는 단순 흐름을 권장합니다.
